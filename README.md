# SeedStartGate

An offline compiler for seed-treatment **do-not-start calendars**. Give it your approved fixed-day handling protocol and your staffed calendars; it lists every allowed, blocked and unknown start date, explains each conflict, and checks a chosen start before exporting dated actions.

This project implements the [BC Tree Seed Centre's documented worksheet workflow](https://www2.gov.bc.ca/assets/gov/farming-natural-resources-and-industry/forestry/tree-seed/tree-seed-centre/tswgnewsbulletin50.pdf) as a small portable utility. It does not choose treatments, interpret testing rules, predict germination, allocate resources or optimize schedules.

Implementation and release verification are in progress. See the issues and pull requests for the supported contract, independent AI-agent reviews and checks.
